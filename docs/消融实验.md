消融实验路径：
1.qattn-qdm:同时启用 G-QCNN 和 Q-SA，使用动态分组策略。 说明 : 这是论文提出的最终方案，性能最佳。实验命令为python train.py \
    --outdir=ablation/qattn_qdm \
    --data="panda_32.zip" \
    --arch=ncsnpp --precond=edm --batch=32 \
    --quantum-frontendqcnn=True \
    --quantum-attn-in-unet=True

2.w/o G-QCNN 禁用量子卷积，保留量子注意力。python train.py \
    --outdir=ablation/wo_gqcnn \
    --data="panda_32.zip" \
    --arch=ncsnpp --precond=edm --batch=32 \
    --quantum-frontendqcnn=False \
    --quantum-attn-in-unet=True

3.w/o Q-SA 保留量子卷积，禁用量子注意力。python train.py \
    --outdir=ablation/wo_qsa \
    --data="panda_32.zip" \
    --arch=ncsnpp --precond=edm --batch=32 \
    --quantum-frontendqcnn=True \
    --quantum-attn-in-unet=False

4.baseline 纯经典模型，即纯经典ncsn++。python train.py \
    --outdir=ablation/baseline \
    --data="panda_32.zip" \
    --arch=ncsnpp --precond=edm --batch=32 \
    --quantum-frontendqcnn=False \
    --quantum-attn-in-unet=False
